# lfbr.it

Sito statico indipendente per il dominio **lfbr.it**.

## Pubblicazione con GitHub Pages
1. Rendere il repository pubblico.
2. Aprire **Settings → Pages**.
3. In **Build and deployment** scegliere **Deploy from a branch**.
4. Selezionare **main** e **/(root)**.
5. Salvare.
6. Impostare/controllare il custom domain **lfbr.it**.

Il file `CNAME` è già presente.
